Como funciona

  1. Detecção

    SIFT: extremos na pirâmide de diferenças de gaussianas, refinados com precisão subpixel e descritos por histogramas de gradiente 4×4×8. Harris: resposta det(A) − α·tr(A)², supressão não-máxima adaptativa e patch MOPS 8×8. Szeliski §7.1.1–7.1.2

  2. Correspondência

    Vizinho mais próximo com teste de razão NNDR = d₁/d₂ e, opcionalmente, checagem cruzada. §7.1.3, eq. 7.18

  3. Translação robusta

    Cada par gera uma hipótese t = x₁ − x₂ (amostra mínima k = 1). O RANSAC escolhe a de maior consenso dentro de ε e ajusta t por mínimos quadrados, que no caso da translação é a média dos inliers. §8.1.2, §8.1.4

  4. Composição

    A imagem 2 é transladada para o quadro global e mesclada por média simples ou por feathering, com pesos lineares em função da distância à borda. §8.4.2

Tudo roda localmente: no GitHub Pages, o mesmo código Python executa no seu navegador via Pyodide (WebAssembly), e nenhuma imagem é enviada a servidores.
